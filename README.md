MediaDeck

MediaDeck is a lightweight desktop music player and library for Windows and Linux.

It lets you keep your music in one place, browse your collection, and enjoy a simple music experience without unnecessary clutter.

The project is still being improved, with more features planned for future updates.

Features

* Clean and simple interface
* Music library
* Built-in audio player
* Fast search
* Playlist support
* Album artwork
* Shuffle and repeat
* Volume control
* Playback progress
* Lightweight performance
* Windows support
* Linux support

Downloads

Windows

Download the latest Windows release:

https://github.com/brovis3243524/MediaDeck/releases/download/v1.0.0/Windows.zip

Installation:

1. Download Windows.zip
2. Extract the archive
3. Open the extracted folder
4. Run MediaDeck.exe

Note: The current release file is named SteamOSMediaDeck.exe. Rename it to MediaDeck.exe if you want the filename to match the project name.

⸻

Linux

Download the latest Linux release:

https://github.com/brovis3243524/MediaDeck/releases/download/v1.0.0/Linux.zip

Installation:

chmod +x MediaDeck
./MediaDeck

Note: The current release file is named SteamOSMediaDeck. Rename it to MediaDeck if you want the filename to match the project name.
